One robot, one wedding, one vow — funny and heartfelt in a single sentence. The entry:

> I have calculated a thousand futures, and in every one where I am happy, you are standing beside me holding the charger.

## Run it

```sh
node main.ts
```

`main.ts` writes the vow to `ENTRY_OUTPUT` or `/output/entry.txt` — a single line, 120 characters, no trailing newline.
